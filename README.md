# Life-on-Mars

A logic-driven console application developed in C# that simulates core genetic operations and DNA sequence analysis. This project models biological data structures and simulates evolutionary transitions across multiple generations.

![21222-1](https://github.com/user-attachments/assets/1c8e05b1-a1c5-4edb-b7ed-18de50886d3f)


## 🚀 Key Technical Highlights

* **DNA Sequence Processing:** Implements algorithms to parse and analyze DNA strands, identifying specific codon sequences and calculating genetic markers.
* **Pattern Matching (Operation 10):** Features a custom sequence search algorithm that identifies the starting positions of specific codon patterns within a larger DNA dataset.
* **Multi-Generational Simulation:** Simulates the creation of new "generations" (BLOBs) by combining and mutating DNA strings, tracking genetic inheritance over time.
* **Mutation & Survival Logic:** Includes a faulty codon ratio analyzer. If the mutation ratio exceeds a 10% threshold, the system simulates a survival failure, terminating the generation line.
* **Genetic Metadata Extraction:** Features logic to determine biological traits (such as gender markers) derived directly from DNA codon analysis.

## 🎮 How it Works

The application provides a menu-driven interface where users can:
1. **Search** for specific codon sequences.
2. **Analyze** the health and traits of a DNA strand.
3. **Simulate** the birth of new generations and monitor the "faulty codon ratio" to determine if the lineage survives or dies out.
